Conception technique

Pensé pour la stabilité et la clarté

Chaque module du launcher remplit un rôle précis, sans couche superflue ni processus résident inutile.

auth.py

Flux OAuth2 Device Code Microsoft

Connexion directe via l'API officielle Microsoft Consumers, suivie de l'échange Xbox Live (XBL), XSTS et Minecraft Services. Vos identifiants ne transitent jamais par le launcher.

Session persistante dans account.json • Rafraîchissement silencieux au démarrage
profile.py

Isolation stricte des profils

Chaque profil dispose de son propre répertoire dédié sous instances/ avec son fichier launcher_profiles.json, évitant tout conflit entre vos mondes, mods ou versions.

Accès direct au dossier du profil en un clic depuis l'éditeur
main.py

Détection RAM & Lancement détaché

Lecture directe de la mémoire physique via l'API Windows GlobalMemoryStatusEx pour borner le curseur d'allocation JVM. Le jeu démarre dans un groupe de processus isolé sans fenêtre console.

Masquage automatique de l'interface en jeu et restauration à la fermeture
Portable Build

Exécutable autonome & Discord RPC

Empaqueté en mode répertoire autonome avec son propre environnement intégré : aucune installation de Python ou de bibliothèques requise sur le PC cible. Intègre l'état en direct sur Discord.

Stockage local plat : config.ini • profiles.dat • account.json

Kanoite Launcher/ Structure d'exécution
Kanoite Launcher.exe Point d'entrée exécutable compilé pour Windows 64-bit. Charge l'interface CustomTkinter et orchestre les threads réseau et jeu.
1

Extraire l'archive du launcher

Téléchargez la dernière release depuis GitHub et décompressez le dossier complet à l'emplacement de votre choix (Bureau, disque secondaire ou clé USB).

2

Lier votre compte Microsoft

Cliquez sur SIGN IN, copiez le code généré et validez-le dans votre navigateur sur microsoft.com/link. La session est ensuite mémorisée localement.

3

Créer un profil et ajuster la RAM

Choisissez une version officielle Mojang, réglez la RAM allouée dans les paramètres selon votre machine, puis cliquez sur PLAY pour télécharger et lancer le jeu.
